# Сохранение базы данных (бэкапы)

На бесплатном Render диск временный: при каждом «засыпании» и обновлении сайта база стирается.
Чтобы аккаунты и анкеты не пропадали, сайт сам сохраняет зашифрованные копии базы
в **приватный** репозиторий GitHub и восстанавливает их при запуске.

## Настройка (один раз)

1. GitHub → **New repository** → имя `workerhub-data`, тип **Private**, поставить галочку **Add a README** → Create.
2. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token:
   - Repository access: **Only select repositories** → `workerhub-data`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Скопировать токен (начинается с `github_pat_`). Никому его не показывать.
3. Render → сервис → **Environment** → добавить переменные:
   - `BACKUP_GITHUB_REPO` = `ваш-ник/workerhub-data`
   - `BACKUP_GITHUB_TOKEN` = токен из шага 2
   - `BACKUP_KEY` = любая длинная случайная строка (сохраните её в заметках: без неё копии не расшифровать)
4. Сохранить. В логах Render появится строка `[backup] enabled ...`.

## Как это работает

- при запуске без файла базы: скачивает последнюю копию и восстанавливает её;
- каждые ~30 секунд, если что-то изменилось, загружает новую копию (хранятся 3 последние);
- при остановке сервиса делает последнюю копию.

Если бэкап настроен, но восстановить его не получилось (нет связи с GitHub, неверный ключ), сайт
**не запускается**, чтобы пустая база не затёрла хорошую копию. Причина будет в логах Render.
